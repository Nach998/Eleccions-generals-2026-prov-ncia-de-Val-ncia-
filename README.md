# Simulador de la Llei d'Hondt - Província de València

Aplicació web interactiva desenvolupada en HTML, CSS i JavaScript pur per calcular el repartiment d'escons (diputats) segons el sistema electoral de la **Llei d'Hondt** aplicat a la **província de València**[cite: 1].

## Característiques principals
* **Assignació de diputats**: Configurat per repartir un total de **16 diputats** (circumscripció de València a les eleccions generals).
* **Edició dinàmica**: Permet modificar tant els noms dels partits polítics com la quantitat de vots rebuts en temps real[cite: 1].
* **Barrera electoral del 3%**: Calcula automàticament el llindar mínim necessari (3% dels vots vàlids) per poder optar al repartiment d'escons[cite: 1].
* **Gestió de files**: Possibilitat d'afegir nous formacions polítiques o eliminar-ne d'existents.
* **Càlcul automàtic de cocients**: Genera la matriu completa de divisió de vots d'1 fins a 16.

## Ús local
1. Clona o descarrega aquest repositori.
2. Obre el fitxer `index.html` en qualsevol navegador web modern.
